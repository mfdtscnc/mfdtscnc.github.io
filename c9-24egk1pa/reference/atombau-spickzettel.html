Atombau und gekürztes PSE

Alles aus dem Heft auf zwei Seiten, dazu die Aufgabentypen der Klausur.

1 · Flammenfärbung und Spektren

Erklärung in 4 Schritten: (1) Elektronen nehmen in der Flamme Energie (Wärme) auf → (2) springen auf eine höhere Energiestufe (angeregter Zustand) → (3) fallen in den Grundzustand zurück → (4) geben die Energie als Licht ab.

Andere Atomart = andere Stufenabstände = andere Farbe.

KCl violett (durchs Cobaltglas) · SrCl₂ dunkelrot · LiCl rot · NaCl orange · CuCl₂ blaugrün. Die Farbe kommt vom Metall.

Spektroskop zerlegt Licht in Farbanteile. Kontinuierliches Spektrum: lückenloser Regenbogen (Sonne, Glühlampe). Linienspektrum: einzelne scharfe Linien auf dunklem Grund, für jedes Element einzigartig („Fingerabdruck“). 1868: Helium im Sonnenlicht entdeckt.

2 · Energiestufenmodell und Elektronenkonfiguration

  • Elektronen auf Energiestufen n = 1, 2, 3 … (Hauptquantenzahl). Je weiter außen, desto energiereicher.
  • Höchstens 2 · n²: n = 1 → 2, n = 2 → 8, n = 3 → 18, n = 4 → 32.
  • Von unten auffüllen. K und Ca: Stufe 3 erst nur 8, dann Stufe 4.
  • Valenzelektronen = Elektronen der höchsten Stufe.

Na: 1² 2⁸ 3¹ · Mg: 1² 2⁸ 3² · Ca: 1² 2⁸ 3⁸ 4²

Große Zahl = Stufe, hochgestellt = Anzahl Elektronen.

Im PSEverrät
OrdnungszahlAnzahl der Elektronen (= Protonen)
Periode (Zeile)Anzahl der besetzten Stufen
Hauptgruppe (Spalte)Anzahl der Valenzelektronen

Edelgasregel (Experten): Atome streben 8 Valenzelektronen an (He: 2) = Edelgaskonfiguration. I.–III. Hauptgruppe geben ab (Na⁺, Mg²⁺, Al³⁺), V.–VII. nehmen auf (N³⁻, S²⁻, F⁻). Kohlenstoff: keine Ionen, sondern Elektronenpaarbindungen.

3 · Ionisierungsenergie

Energie, die erforderlich ist, um ein Elektron vollständig aus der Atomhülle zu entfernen: A → A⁺ + e⁻. Man arbeitet gegen die Anziehungskraft des positiven Kerns.

  • Gruppe, von oben nach unten: nimmt ab. Neue Stufe → Valenzelektronen weiter vom Kern → schwächer angezogen.
  • Periode, von links nach rechts: nimmt sägezahnartig zu. Mehr Protonen → stärkere Anziehung auf derselben Stufe. Maxima: Edelgase. Minima: Alkalimetalle.
  • Nacheinander abgespaltene Elektronen: Die Werte steigen, und an einer Stelle gibt es einen großen Sprung. Elektronen vor dem Sprung = Valenzelektronen = Hauptgruppe. Mg: Sprung nach dem 2. → II. Hauptgruppe.

Antwortmuster für „Begründe“ (Trend im PSE)

Trend (nimmt ab/zu) + weil + Ursache (Abstand zum Kern / Protonenzahl) + Folge (Anziehungskraft kleiner/größer).

Antwortmuster für „Beurteile“

1. Urteil in einem Satz („Die Aussage ist falsch.“) 2. Begründung mit Fachbegriff („…, weil das Kern-Hülle-Modell keine festen Energiestufen kennt.“) 3. Was stattdessen stimmt.
